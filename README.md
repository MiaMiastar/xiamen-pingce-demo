# 供应链模型评测平台 Demo

面向供应链行业的模型评测产品前端 Demo，仅包含前端交互与本地 Mock 数据，无需后端即可运行。

## 功能概览

### 评测数据集
- **数据集展示与检索**：平台内置评测数据集的统一展示，支持按名称/描述搜索、按领域筛选。

### 榜单
- **榜单集合页**：展示所有已发布榜单，支持按时间周期查看，展示核心排名信息。
- **榜单详情页**：单个榜单的完整排名、规则说明、评测依据与评分逻辑，以及各参与模型的详细得分。

### 工作台 · 评测管理
- **任务管理**：统一管理评测任务，展示状态与核心结果，支持查看、编辑、删除。
- **任务新建**：选择模型与数据集，完成配置后提交执行。
- **评测报告**：单次任务的完整结果、基础信息与指标，支持图表展示。
- **报告对比**：多份报告横向对比，展示不同模型在同一评测集下的指标差异。
- **报告下载**：支持将报告下载为文本文件。
- **任务编辑**：对草稿/未执行任务修改名称、模型或数据集。
- **任务删除**：删除任务（删除后不可恢复）。

### 模型管理
- **模型管理**：管理接入的评测模型，支持新增、编辑、删除。
- **新建模型**：填写基础信息与 API 调用参数。
- **模型编辑**：修改模型信息与 API 配置。
- **模型删除**：删除后不可再用于新建评测任务。

### 系统
- **操作日志**：记录用户关键操作，便于追溯与审计。
- **个人信息**：查看与修改个人基础信息。
- **用户登录**：登录认证（Demo 下任意账号密码即可进入）。

## 运行方式

```bash
npm install
npm run dev
```

浏览器访问终端提示的地址（通常为 http://localhost:5173）。首次进入会跳转登录页，输入任意账号密码即可进入系统。

## 技术栈

- React 19 + Vite 7
- React Router 7
- Recharts（图表）
- 纯前端 Mock 数据，任务与模型的增删改仅保存在当前会话内存中，刷新后恢复默认数据。
